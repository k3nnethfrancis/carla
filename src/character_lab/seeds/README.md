# Starter library

These documents ship as package data and appear offline in every new installation.
They are available in the shared Library, not automatically selected in workspaces.
A local library JSON with the same key overrides its bundled entry.

- **Meditations** — Marcus Aurelius, George Long translation, Project Gutenberg
  #15877: https://www.gutenberg.org/ebooks/15877. 487 numbered passages across
  twelve books. Paragraphs retained; editorial footnotes excluded. This historical
  translation is public domain in the United States.
- **Tractatus** — Ludwig Wittgenstein, C. K. Ogden translation, Project Gutenberg
  #5740: https://www.gutenberg.org/ebooks/5740. Only the seven main propositions,
  not the full book. This historical translation is public domain in the United States.

Each JSON preserves source URLs, source hashes, normalization notes and passage IDs.
Hashes identify the original downloaded sources, not the normalized JSON files.
Carla's MIT license covers its code, not these authors' texts.

Gunkel's Paths table is linked in [research context](../../../docs/resources.md)
but is not bundled: redistribution permission has not been verified.
